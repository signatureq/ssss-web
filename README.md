# ssss / web developer

Персональный сайт-визитка о веб-дизайне и разработке. Telegram: [@added08](https://t.me/added08).

Основной домен: [ssss-web.ru](https://ssss-web.ru/). Хостинг — GitHub Pages.

Актуальный репозиторий сайта и настроек Pages — `signatureq/ssss-web`. Репозиторий `signatureq/ssss-web-developer` содержит предыдущую версию; Pages в нём отключён.

Визуальное направление вдохновлено midu.design. Вёрстка, тексты, графика и WebGL-эффект написаны для этого проекта; чужие работы и отзывы не используются.

## Запуск

Требуется Node.js 20.19+ или 22.12+.

```sh
npm install
npm run dev
```

Сайт откроется на http://127.0.0.1:5173/.

## Сборка

```sh
npm run build
npm run preview
```

Папка `dist` — готовая статическая версия.

## Публикация

GitHub Pages автоматически обновляется после push в `main`. Workflow `.github/workflows/deploy.yml` устанавливает зависимости, собирает сайт и публикует `dist`.

Сборка для собственного домена использует корневой путь `/`:

```sh
npm run build
npm run preview
```

Локальная разработка остаётся на корневом пути `/`. В настройках репозитория Pages выбран источник GitHub Actions.

## Домен

В GitHub Pages указан Custom domain `ssss-web.ru`. В DNS-панели домена нужны следующие записи:

| Тип | Имя | Значение |
| --- | --- | --- |
| A | @ | 185.199.108.153 |
| A | @ | 185.199.109.153 |
| A | @ | 185.199.110.153 |
| A | @ | 185.199.111.153 |
| CNAME | www | signatureq.github.io |
| CAA | @ | 0 issue "letsencrypt.org" |

TTL — 3600 секунд или значение по умолчанию. После распространения DNS GitHub выпускает сертификат; в Pages нужно проверить состояние сертификата и Enforce HTTPS. При публикации через Actions отдельный файл CNAME не требуется.

### Проверка HTTPS

На 10 октября 2026 года публикация работает: HTTP возвращает `200 OK`. Четыре A-записи и `www` CNAME подтверждены через Google DNS, Cloudflare DNS и диагностический workflow на GitHub. DS-записей DNSSEC нет; до проверки CAA-записей тоже не было. При этом Pages health check возвращает `InvalidDNSError` и `caa_error: Dnsruby::ServFail`; HTTPS обслуживается сертификатом, не соответствующим домену. Однократная повторная привязка домена не устранила ошибку.

В REG.RU добавлена явная CAA-запись `@ 0 issue "letsencrypt.org"`, разрешающая выпуск сертификата центру GitHub Pages. Запись сохранена в панели, её распространение и выпуск сертификата пока не подтверждены. Отсутствие CAA само по себе не было ошибкой; запись добавлена для проверки сбоя CAA-запросов. Остальные записи и DNS-серверы не изменялись.

Это не ошибка сборки сайта. Следующий шаг — проверить доступность DNS-проверок GitHub к `ns1.reg.ru` / `ns2.reg.ru` и передать диагностику поддержке REG.RU или GitHub. Смена DNS-хостинга требует переноса всех записей зоны; не менять NS без сохранения зоны. После успешной DNS-проверки и выпуска сертификата включить Enforce HTTPS.

Диагностика: [запуск workflow от 10 октября](https://github.com/signatureq/ssss-web/actions/runs/37988676514). Настройки: [GitHub Pages](https://github.com/signatureq/ssss-web/settings/pages). Проверка API: `gh api repos/signatureq/ssss-web/pages/health`.

## Портфолио

Раздел `#portfolio` доступен из меню и из шапки на компьютере. Превью главных страниц хранятся локально в `public/portfolio`; изображения загружаются лениво, ссылки открываются в новой вкладке.

- [Выгодные квартиры](https://krasnodarkvartir.ru/) — недвижимость.
- [Добро и Тортики](https://dobroitortiki.ru/) — кондитерская школа.
- [White Studio](https://whitestudio-ekb.ru/) — детейлинг.
- [BEST-TRANS](https://best-trans.su/) — международная логистика.

Скриншоты сделаны с опубликованных главных страниц 10 октября 2026 года. Список проектов и ссылки предоставлены владельцем сайта. Чтобы обновить превью, заменить соответствующий JPEG; названия, категории и ссылки находятся в `index.html`.

## Состав

- `index.html` — тексты, блоки и ссылки.
- `src/style.css` — оформление и мобильная версия.
- `src/main.js` — плавный скролл, меню и переключение сцен.
- `src/hero-light.js` — медленно переливающийся WebGL-фон с плавной реакцией на мышь.
- `src/process.js` — геометрическая анимация блока с этапами работы.
- `public/fonts` — локальные шрифты Manrope, лицензия OFL.
- `public/portfolio` — скриншоты главных страниц четырёх проектов.

Vite, GSAP и Lenis. Отсутствуют аналитика, cookie-баннеры, внешние iframe и формы сбора данных. При `prefers-reduced-motion` движение отключается. Если WebGL недоступен, остаётся статичный фон.
